
# 📈 Nigerian Stock Market Analysis (2022–2026)

An end-to-end data analytics project analyzing the performance of selected Nigerian Exchange (NGX) listed companies using **Excel, Power Query, SQL, and Power BI**.

---

## 📌 Project Overview

This project explores the historical performance of 15 companies listed on the Nigerian Exchange (NGX) between 2022 and 2026.

The objective is to transform raw stock market data into meaningful business insights through data cleaning, exploratory data analysis, SQL queries, and interactive dashboards.

---

## 🎯 Business Objectives

This analysis answers questions such as:

- Which company recorded the highest average monthly return?
- Which sector performed best during the analysis period?
- Which company had the highest trading volume?
- Which stock was the most volatile?
- How did stock performance change over time?

---

## 📊 Dataset

**Source:** Investing.com

**Period Covered:** 2022–2026

**Companies Analysed:** 15

**Sectors Covered:**

## 🧹 Data Cleaning

The dataset was cleaned using Power Query.

The following transformations were performed:

- Combined stock data from multiple companies
- Standardized company names
- Added sector classification
- Converted trading volume into numeric values
- Corrected date formats
- Created Year, Month and Quarter columns
- Calculated Price Range
- Calculated Monthly Return (%)

---

## 📈 Exploratory Data Analysis

The analysis focused on:

- Average Monthly Return by Company
- Average Closing Price
- Average Trading Volume
- Sector Performance
- Stock Volatility
- Yearly Performance
- Monthly Trends

- **Best Performing Company:** Fidson
- **Best Performing Sector:** Healthcare
- **Highest Average Monthly Return:** 10%
- **Highest Average Trading Volume:** Access Holdings
